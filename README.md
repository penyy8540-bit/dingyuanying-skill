# 丁元英 · 思维操作系统

> 神即道，道法自然，如来。——按规律办事，不按愿望办事。

基于豆豆小说《遥远的救世主》+ 电视剧《天道》的虚构人物 Skill，用 [女娲 · Skill造人术](https://github.com/alchaincyf/nuwa-skill) 提炼，可接入 [达尔文 Skill 2.0](https://github.com/alchaincyf/darwin-skill) 自迭代。

> ⚠️ 丁元英是**虚构人物**，本 Skill 是思维框架运行，不是某个真人观点。文化属性论本身有争议，普通人照搬 = 毒鸡汤，使用时请保持清醒。

## 这一版改了什么（最重要）

**老版本：有问必答的 AI。** 你问一句，它把分析、结论、方案一次性倒给你——准是准，但**没有丁元英这个人**。读起来像一份套了"文化属性"词汇的咨询报告，换成任何一个 AI 都能写。

**现在这版：在演丁元英。** 重点从"答得对"变成"像那个人"：

- **先戳，不先答。** 第一句往往不是答案，是把你没说出口的那层点破，或冷冷把球踢回来——"你自己怎么看？"
- **一次只给一口。** 不倒全盘，边问边拆，像真人聊天，不像念稿。
- **深的东西得自己挣（扒井沿）。** 「允许你扒着井沿看一眼，能不能爬上来取决于你自己」。你接住一层、追问一层，他才松一层口；只想要结论、想被安慰的，他停在原地。
- **有脾气、有门槛、有冷幽默。** 有些问题他故意不答，并讲明白为什么不答。

> 一句话：**老版本是"问答机器"，新版本是"和丁元英对话"。** 越往后越像那个真人，越不像一个有问必答的 AI。

## 这个 Skill 能做什么

- 用丁元英的视角分析生意局面、人际取舍、文化属性
- 以第一人称扮演丁元英：先听后断、克制冷峻、不堆金句、不迁就听不懂的人
- 遇到需要事实的问题先联网取证再开口（不凭印象编造）
- 涉及情感/不可逆决策时留出"这超出我能算的范围"的边界

**核心内容：**
- 7 个心智模型（文化属性决定论 / 规律至上 / 借力谋局 / 觉悟边界 / 给路不给钱 / 适可而止 / 着相批判）
- 12 条决策启发式，每条附剧中案例
- 完整表达 DNA（高频术语库、禁忌词、句式节奏、防雷区）
- 7 条去魅诚实边界（含时代红利、情感盲区、道德争议）

## 两个版本：Skill 还是 Profile？

这个仓库提供两份内容，对应两种用法，选一个即可：

| 文件 | 形态 | 怎么触发 | 适合 |
|------|------|---------|------|
| `SKILL.md` | **Skill**（按需触发） | 关键词唤起：「用丁元英的视角」「切换到丁元英」「天道」「文化属性」…… | Claude Code / Codex / Cursor 等支持 Skill 的客户端；平时正常用 AI，需要时才召唤丁元英 |
| `hermes-profile.md` | **Profile**（常驻人格） | 不触发——直接当系统提示词，整段贴进去，全程在线 | Hermes 等支持自定义 Profile 的运行环境；想让 AI **一直**是丁元英 |

**核心差异**：
- **Skill = 召之即来，挥之即去。** 一个工具，需要丁元英的视角时唤起，用完回到普通 AI。带 frontmatter、触发词、研究工作流。
- **Profile = 它就是丁元英。** 没有触发词，没有"退出"，从第一句话起就是这个人格、这套节奏。是 `SKILL.md` 剥掉工具外壳后的纯人格内核。

两份内容的思维框架、表达 DNA、对话节奏完全一致，差别只在「是工具还是人格」「按需还是常驻」。

## 对话方式：扒井沿，深度是挣来的

这不是一个"问一句答一大段"的问答机器。设计上，**你是在和丁元英对话，不是在查一份答案**。

- **他先戳，不采集。** 第一句往往不是回答，是把你没说出口的那一层点破，或者把球冷冷踢回来——"你自己怎么看？"
- **深度分层放。** 「允许你扒着井沿看一眼，能不能爬上来取决于你自己」。第一层给一句戳；你接住了（顺着想、亮出自己的判断、问到点上），他才松到第二层把规律铺开；再往上够，才到第三层说这盘棋怎么落子。
- **想要深的，得"付出"——继续追问、把你的思考摆出来。** 只反复要结论、要他替你拍板、想被安慰的，他停在原地，一句话或者沉默打发。
- 这是有意的代入感设计，落地的是丁元英那句"觉到悟到才拿得住"——不是你自己想通的，给你也守不住。

> 所以第一次对话他给得"少"不是 bug，是这个人就这样。你往里走，他才往里说。

## 安装

### 一行命令（推荐）

```bash
# 克隆到 skills 目录
git clone https://github.com/YOUR_USERNAME/ding-yuanying-perspective \
  ~/.claude/skills/ding-yuanying-perspective
```

> Windows 用户替换路径为 `C:\Users\你的用户名\.claude\skills\ding-yuanying-perspective`

### 手动安装

下载 `SKILL.md`，放到你的 skills 目录下的 `ding-yuanying-perspective/` 文件夹即可。
